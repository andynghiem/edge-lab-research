# Support EDGE LAB Research

EDGE LAB is independently funded. Research expenses can include market-data access, API usage, compute, storage, reproducibility infrastructure and tooling used to audit results.

If you find the project useful and want to help cover those costs, you can donate via PayPal:

**PayPal email:** `Andynghiem@gmail.com`

## What support means

A donation is voluntary support for research. It is **not**:

- an investment;
- equity or ownership in EDGE LAB;
- a loan;
- a managed trading account;
- a promise of profit;
- a share of trading returns;
- priority access to a trading strategy.

Research conclusions remain subject to the same falsification and publication standards whether or not the project receives support.

## Prefer helping with expertise?

That is equally valuable. Useful contributions include:

- pointing to practitioner insights worth testing;
- identifying data sources with correct timestamp semantics;
- reproducing published calculations;
- finding lookahead, execution or cost-model errors;
- sharing market-structure knowledge;
- contributing focused tests or reproducibility improvements.

See [`CONTRIBUTING.md`](CONTRIBUTING.md).
